# 미르니 전리품 상자 시뮬레이터

월드오브탱크 2026 미르니 이벤트 전리품 상자 결과를 시뮬레이션하고, 실제 개봉 결과를 수동 입력해 운 지수와 구매 비용을 계산하는 웹 애플리케이션입니다.

## 주요 페이지

- `index.html`: 전리품 상자 개봉 시뮬레이터
- `luck-calculator.html`: 실제 개봉 결과 기반 운 지수 계산기
- `debug.html`: 데이터/동작 확인용 보조 페이지

## 핵심 기능

### 상자 시뮬레이터

- 파편, 조각, 코어 3종 상자 지원
- 상자별 천장 시스템 반영
  - 파편: 50개
  - 조각: 40개
  - 코어: 20개
- 슬롯별 확률 데이터 기반 보상 추첨
- 전차/치장품 등 `y: true` 보상 획득 여부 추적
- 이미 획득한 보상은 남은 미획득 보상으로 확률 재분배
- 중복 획득 시 대체 보상 처리
- 상자 보상으로 획득한 추가 상자 자동 인벤토리 반영
- 상자별 1개 열기, 5개 열기, 모두 열기 지원
- 대량 개봉 시 성능 최적화 렌더링 적용
- 상세 로그에서 개봉 순서, 슬롯, 수량, 신규/대체/천장 여부 표시
- 전체 초기화 지원

### 상점 및 비용 관리

- `shop_data.json` 기반 파편 상자 패키지 자동 렌더링
- 무료 10개 상자 1회 수령 처리
- 유료 패키지 구매 시 보유 상자와 총 구매 비용 자동 갱신
- 데스크탑 상점 패널과 모바일 상점 모달 지원
- 총 구매 비용 실시간 표시

### 보유 상태 관리

- 전차와 치장품 보유 체크리스트 제공
- 체크된 보상은 추첨 시 이미 보유한 항목으로 처리
- 획득 시 자동 체크 처리
- 체크리스트 항목 전체 클릭/Enter/Space로 체크 및 해제 가능
- 차고 보유 전차/치장품 사전 설정 모달 제공
- 사전 보유 설정은 `localStorage`에 저장
- 모바일 사이드바에서 보유 상태 확인 및 수정 가능

### 누적 획득 종합 보고서

- 종합 운 지수 표시
- 전차 획득/미획득 현황 표시
- 치장품 획득 현황 표시
- 자원, 물자, 승무원 교본, 추가 상자, 기타 보상 분류 표시
- 소모품 및 자원 기대값 대비 실제 획득량 비교
- 상자별 통계 표시
  - 개봉 수
  - 실제 전차 획득 수
  - 기대 전차 획득 수
  - 운 좋음/평균/운 나쁨 판정
- 크게 보기 모달 제공
- 보고서 텍스트 복사 지원
- JSON 다운로드 지원
- CSV 다운로드 지원

### 운 지수 계산기

`luck-calculator.html`은 실제로 개봉한 결과를 직접 입력해 운 지수를 계산하는 페이지입니다.

- 5단계 입력 흐름
  - 상자 구매 + 획득 상자
  - 획득 전차
  - 획득 치장품
  - 획득 소모품
  - 결과 확인
- 탭별 현재 입력 상태 표시
  - 상자 총 개봉 수
  - 선택 전차 수
  - 치장품 입력 수
  - 소모품 입력 수
  - 결과 계산 상태
- PC 화면에서는 입력 카드 3열 배치
- 모바일 화면에서는 단일 컬럼 중심의 터치 친화 레이아웃 유지
- 패키지 구매는 `+/-` 버튼으로 수량 조절
- 무료 상자는 `-1`, `+1`, `+10` 버튼으로 조절
- 추가 획득 상자는 사용자가 숫자로 직접 입력
- 전차 획득은 체크박스로 입력
- 전차 체크 카드 전체 클릭/Enter/Space로 체크 및 해제 가능
- 치장품과 소모품은 숫자 입력
- 숫자 입력 카드 전체 클릭 시 해당 입력칸 포커스
- 이전/다음 탭 이동 버튼 제공
- 어디서든 결과 확인 가능
- 탭별 초기화 지원
  - 상자 입력 초기화
  - 전차 선택 해제
  - 치장품 입력 초기화
  - 소모품 입력 초기화
- 결과 계산 전에는 크게 보기/복사/JSON/CSV 버튼 비활성화
- 입력값 변경 시 기존 결과를 만료 처리하고 재계산 필요 상태 표시
- 기존 시뮬레이터와 동일한 종합 운 지수 규칙 사용

### 운 지수 계산 규칙

종합 운 지수는 아래 비율로 계산됩니다.

- 전차 운: 75%
- 상자 드롭 운: 15%
- 소모품 운: 10%

점수는 낮을수록 운이 좋은 것으로 해석하며, UI에서는 `상위 n%`, `평균`, `하위 n%` 형태로 표시합니다.

수동 운 지수 계산기에서는 전차별 획득 시점을 알 수 없으므로, 개별 전차 행에는 단일 행운/불운 판정을 표시하지 않습니다. 대신 전체 종합 운 지수와 상자별 통계에는 전차 획득 수 기반 운 판정이 반영됩니다.

## 데이터 파일

### `gacha_data.json`

상자별 슬롯, 그룹 확률, 아이템 확률, 수량, 대체 보상, 전차/치장품 여부를 정의합니다.

주요 구조:

```json
{
  "파편": {
    "slots": [
      {
        "id": "슬롯1",
        "groups": [
          {
            "prob": 0.02,
            "items": [
              {
                "name": "Alby",
                "prob": 0.1,
                "qty": 1,
                "y": true
              }
            ]
          }
        ]
      }
    ]
  }
}
```

### `shop_data.json`

상점 패키지와 무료 상자 정보를 정의합니다.

```json
{
  "title": "파편 상자",
  "targetBox": "파편",
  "packages": [
    {
      "id": "p230",
      "label": "230개",
      "count": 230,
      "price": 394640,
      "freeOnly": false
    }
  ]
}
```

## 실행 방법

정적 파일 기반 프로젝트이므로 별도 빌드 과정은 없습니다.

### 방법 1. 로컬 서버 실행

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:8000/index.html
http://127.0.0.1:8000/luck-calculator.html
```

### 방법 2. 파일 직접 열기

브라우저에서 `index.html`을 직접 열 수 있습니다. 다만 브라우저 보안 정책에 따라 `fetch()`로 JSON 파일을 불러오는 동작이 제한될 수 있으므로 로컬 서버 실행을 권장합니다.

## 사용 방법

### 시뮬레이터 사용

1. `index.html`을 엽니다.
2. 필요하면 `차고 보유 전차 설정`에서 이미 보유한 보상을 체크합니다.
3. 상점에서 무료 상자 또는 유료 패키지를 구매합니다.
4. 보유한 상자를 1개, 5개, 모두 열기로 개봉합니다.
5. 상세 로그와 누적 획득 종합 보고서를 확인합니다.
6. 필요하면 보고서를 복사하거나 JSON/CSV로 다운로드합니다.

### 운 지수 계산기 사용

1. `luck-calculator.html`을 엽니다.
2. 구매한 상자 패키지와 무료 상자 수를 입력합니다.
3. 개봉 중 획득한 추가 상자를 입력합니다.
4. 획득한 전차를 체크합니다.
5. 획득한 치장품과 소모품 수량을 입력합니다.
6. `결과 확인`을 눌러 종합 운 지수와 보고서를 확인합니다.
7. 필요하면 크게 보기, 복사, JSON, CSV 다운로드 기능을 사용합니다.

## 커스터마이징

### 천장 한도 변경

`simulator.js`와 `luck-calculator.js`의 `PITY_LIMIT` 값을 수정합니다.

```javascript
const PITY_LIMIT = { '파편': 50, '조각': 40, '코어': 20 };
```

### 상자 가치 가중치 변경

운 지수 계산에서 사용하는 상자 가치 가중치는 `BOX_WEIGHTS`에서 수정합니다.

```javascript
const BOX_WEIGHTS = { '파편': 1, '조각': 6.3, '코어': 36 };
```

### 상점 패키지 변경

`shop_data.json`의 `packages` 배열을 수정합니다.

### 보상/확률 변경

`gacha_data.json`의 상자별 `slots`, `groups`, `items`를 수정합니다.

## 알려진 제약

- 운 지수 계산기는 사용자가 전차를 몇 번째 상자에서 획득했는지 입력하지 않으므로, 전차 개별 획득 시점 기반 행운/불운 판정은 제공하지 않습니다.
- 수동 입력 결과는 브라우저 세션 내에서 계산되며, 저장하려면 JSON 또는 CSV 다운로드를 사용해야 합니다.
- 파일 직접 열기 환경에서는 브라우저 정책에 따라 JSON 로드가 제한될 수 있습니다.
